# Khongor Self-Service Kiosk

Ажилтан нэвтрэхгүй, хэрэглэгч шууд хоол сонгох босоо киоск интерфэйс. Дэлгэцийг 1080 × 1920 portrait горимд тааруулсан.

## Ажиллуулах

Репозиторийн үндсэн хавтсаас:

```bash
pnpm --filter desktop dev
```

Production renderer болон Electron shell бэлдэх, нээх:

```bash
pnpm --filter desktop build
pnpm --filter desktop start
```

## Хэрэглэгчийн урсгал

1. Нэвтрэхгүйгээр хоолны ангилал, жагсаалтыг нээж үзнэ.
2. Хоол нэмж сагсаа шалгана.
3. Төлбөрийн алхмын дараа eBarimt-ийн хувь хүн/байгууллага төрлийг сонгоно.
4. Баримтаа хэвлэмэл эсвэл цаасгүй QR хэлбэрээр авах сонголт хийнэ.

Одоогоор цэс жишээ өгөгдөлтэй. Төлбөрийн төхөөрөмж, сервер/API, eBarimt POS үйлчилгээ, бодит QR болон принтер холбогдоогүй. Тиймээс checkout болон баримтын алхмууд нь туршилтын UI бөгөөд захиалга хадгалахгүй, төлбөр хийхгүй, хэвлэхгүй. QR дэлгэцийн дүрслэл нь бодит eBarimt QR биш. Үйлдвэрлэлийн хэрэглээнд төлбөрийн provider, merchant бүртгэл/тохиргоо, eBarimt холболт, хэвлэгчийн драйвер болон backend checkout endpoint шаардлагатай.

Electron preload нь зөвхөн display info болон fullscreen удирдах `window.desktopShell` API-г гаргаж, renderer-д Node.js хандалт өгөхгүй.
